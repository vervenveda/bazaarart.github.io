How to use this unit

  1. Begin each week with the essential question, vocabulary and original worked example.

  3. Keep original process evidence, accurate source citations and a documented critique/revision.
  4. Save and export the Week-specific JSON packet. Formative quiz scores do not substitute for educator review.
