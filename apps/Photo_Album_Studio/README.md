Photo Album Studio

Photo Album Studio is a local-first, multi-purpose album builder for the Bazaar Art repository.

Children's story albums

Artist portfolios

Work presentations

School projects

Main features

Album library search

Seven visual themes

Light and dark application interfaces

One-photo, photo-and-text, two-photo, four-photo, full-bleed, text, and section-title layouts

Bulk photo-to-page creation

Page duplication and reordering

Captions and accessible alt text

Purpose-specific metadata

Children's stickers and visual markers

Presentation mode

Full-screen presentation

Print and PDF layout

Album JSON backup

Complete-library backup

Portable, self-contained HTML album export

Migration from the earlier sovereign_album_v3 browser album

Import of earlier JSON album backups

IndexedDB storage with localStorage fallback

Automatic image resizing and WebP/JPEG compression

Privacy

Photos remain in the browser unless the user deliberately exports an album.

Browser storage can be cleared by the user, browser, operating system, or device-management process. Important albums should be exported regularly.

Review photographs, names, locations, dates, children's information, workplace information, and artwork details before sharing an exported album.
